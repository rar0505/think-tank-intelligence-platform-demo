# Think Tank Intelligence Platform

Система автоматического мониторинга и анализа публикаций международных аналитических центров (think tanks).

Проект собирает публикации из заданного набора аналитических центров, определяет их релевантность пользовательскому запросу, анализирует содержание и формирует структурированный аналитический отчёт с указанием источников.

## Задача проекта

Аналитические центры ежедневно публикуют большое количество исследований, докладов и экспертных материалов. Ручной поиск и анализ таких публикаций занимает значительное время.

Цель проекта — автоматизировать этот процесс:

- определить, какие аналитические центры релевантны запросу;
- найти их актуальные публикации;
- отфильтровать нерелевантные материалы;
- определить актуальность публикаций;
- извлечь ключевые факты, позиции, риски и прогнозы;
- сопоставить информацию из нескольких источников;
- сформировать итоговый аналитический отчёт.

## Архитектура

Система построена как последовательность специализированных агентов:

```text
Запрос пользователя
        ↓
Query Analysis Agent
        ↓
Source Selection Agent
        ↓
Think Tank Registry
        ↓
Collection Agent
        ↓
Source Validation Agent
        ↓
Relevance Agent
        ↓
Freshness Agent
        ↓
Diversity Ranking Agent
        ↓
Extraction Agent
        ↓
Methodologist Agent
        ↓
Writer Agent
        ↓
Reviewer Agent
        ↓
Аналитический отчёт
```

Каждый этап отвечает за отдельную часть обработки данных. Такой подход позволяет независимо изменять алгоритмы поиска, фильтрации, анализа и формирования отчётов.

## Основные возможности

- сбор публикаций с сайтов аналитических центров;
- реестр разрешённых источников;
- автоматический выбор источников под пользовательский запрос;
- проверка и очистка собранных материалов;
- оценка релевантности;
- определение даты и актуальности публикации;
- ранжирование материалов;
- контроль разнообразия источников;
- извлечение фактов, позиций, прогнозов, рисков и числовых данных;
- формирование аналитического отчёта;
- проверка итогового отчёта отдельным агентом;
- резервная локальная обработка при недоступности LLM.

## Пример запроса

```text
Что аналитические центры говорят о России, нефти, топливе и санкциях?
```

Система определяет тематику запроса, выбирает подходящие аналитические центры, собирает публикации и оставляет материалы, соответствующие заданной теме.

Результатом является структурированный отчёт с указанием организаций, публикаций и исходных ссылок.

## Статус

Проект находится в разработке.

Реализован прототип многоэтапного процесса обработки запроса: от анализа темы и сбора публикаций до ранжирования источников, извлечения информации и формирования аналитического отчёта.

Ведётся работа над расширением базы аналитических центров, повышением качества семантического поиска и улучшением итоговых отчётов.
